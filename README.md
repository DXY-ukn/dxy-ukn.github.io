# Xiangyu Ding

Personal academic website: https://dxy-ukn.github.io/

This is a plain HTML and CSS website hosted with GitHub Pages from the root of the `main` branch.

The homepage combines About me, education, the Chern scholarship, a short research overview, and the paper list. The portrait is aligned to the right. Published and accepted papers appear first.

To update the page, edit `index.html`; layout is in `style.css`. Paper downloads are in `papers/`. The CV and research-summary PDFs in `documents/` remain available at their original URLs, while their essential content is presented directly on the page. Update `index.html` and `sitemap.xml` dates when changing the site. Commit changes to `main` to publish them.
