# Xiangyu Ding

Personal academic website: https://dxy-ukn.github.io/

This is a plain HTML and CSS website hosted with GitHub Pages from the root of the `main` branch.

To update the biography or paper list, edit `index.html`. Replace the corresponding PDF in `documents/` when updating the CV or research summary. Paper downloads are in `papers/`. Update the date in `index.html` and `sitemap.xml` when changing the site. Commit changes to `main` to publish them.
